# Dia 1

## Objetivo

- Primeiro contato com a linguagem Python.
- Aprender os primeiros comandos básicos em Python.

## Conceitos aprendidos

### `Variáveis`

    Podem armazenar valores dentro da memória do computador. Uma variável pode ser declarada utilizando o sinal de igual =.
    
    - Exemplo: nome = "Bagha"

### `print()`

    Comando utilizado para mostrar ou escrever comandos na tela, pode receber qualquer tipo de valor como parâmetro, incluindo variáveis.

    - Exemplo: print("Olá!")

### `input()`

    O input pode ser utilizado para pausar o código e aguardar uma resposta do usuário. Também pode ser utilizado para coletar as respostas de um usuário e guardar em uma variavél.

    - Exemplo: nome = input("Digite seu nome: ")
